# Something-Cool

## Red Rising RPG (working title)

A tabletop roleplaying game for the Red Rising universe, designed by and for a group that plays D&D 5e and has read every book in the series.

The goal is a rule set built for this universe: one that takes the parts of other RPGs that players like most and shapes them around the Colors, the Society and the themes of the books.

## Status: planning

No rules are written yet. These documents are the design foundation. They record what the group has decided, what is still open, and the ideas we want to test. Everything marked **Proposal** is open to discussion and change.

## How to give feedback

- Open a GitHub issue for each topic you want to discuss (for example "Dice core" or "Pink edges").
- Or leave comments on a pull request with these docs, if one is open.
- Or tell the GM, who records decisions in [00 Decisions](design/00-decisions.md).
