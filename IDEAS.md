# Saved ideas

Ideas we liked and want to come back to. Neither has been started.

## 1. A civilization that lives in the git history

A made-up world written as a few hundred commits, one for each year of its history.

- `git log` reads as the world's history.
- Checking out an old commit shows the map and the state of the world in that year.
- Branches hold alternate histories, such as "what if the river city won the war."
- The README map on GitHub always shows the present day.

**Riskiest assumption:** a story told through commit messages and diffs has to be fun to browse, not just clever.

## 5. A nature documentary about creatures that evolved overnight

Run an evolution simulation of small soft-bodied creatures for a whole night, then turn the results into a real documentary.

- **Format:** an actual video with voiceover, not a text page.
- **Narration:** the calm, measured, authoritative and slightly wry voice you expect from a mature nature documentary. The voice is original, in that style, not a copy of any real narrator.
- **Story:** the first clumsy movers, the species that took over, and the odd branches that died out, told as natural history.

**Riskiest assumption:** the simulation has to produce distinct, surprising species instead of one dull winner.

**To check when we start:** a text to speech option for the narration, video encoding tools, a renderer for the simulation frames, and enough run time for the simulation.
